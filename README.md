# زخرفة — Zakhrafa

استوديو أسماء عربي أولًا: زخارف عربية وإنجليزية جاهزة للنسخ، ومولّد بطاقات معايدة فاخر يُرسم بالكامل داخل المتصفح.

Arabic-first name decorator and greeting card studio. Static HTML, CSS, and vanilla JavaScript — no build step, no backend, no frameworks.

---

## المزايا الرئيسية

- **زخرفة الأسماء فورًا:** أكثر من ٦٠ زخرفة عربية تحافظ على اتصال الحروف، وأكثر من ٦٠ نمطًا لاتينيًا.
- **نسخ بلمسة واحدة:** مع تنبيهات نجاح وأخطاء، ودعم لوحة المفاتيح.
- **بطاقات معايدة:** ١٠ مناسبات × ٤ قوالب = ٤٠ قالبًا مرسومًا بالكامل على Canvas، بخطوط عربية أصيلة.
- **مقاسان:** مربّع ١٠٨٠×١٠٨٠ وستوري ١٠٨٠×١٩٢٠.
- **تنزيل ومشاركة:** PNG عالي الدقة، مشاركة أصلية عند دعمها، وبديل تنزيل + واتساب.
- **رابط تصميم قابل للمشاركة:** إعدادات البطاقة تُحفظ في `location.hash`.
- **مفضلة وسجل:** محفوظة محليًا لكل زائر أو حساب Google، مع دمج تلقائي لمجموعة الزائر عند أول تسجيل دخول.
- **نسخ احتياطي JSON:** تصدير واستيراد مع تحقق من الملف ودمج دون حذف.
- **عربي/إنجليزي:** تبديل كامل للاتجاه والواجهة، وحفظ اللغة والمظهر.
- **وضع داكن فاخر ووضع فاتح:** ذهبي هادئ، زجاجية، وحركة تحترم `prefers-reduced-motion`.
- **SEO + PWA:** عناوين وأوصاف فريدة، Open Graph، hreflang، JSON-LD، sitemap، manifest، وservice worker للملفات المحلية فقط.
- **إعلان واحد:** Monetag فقط، في `<head>` في كل صفحة، ولا يُخزّن في الـservice worker.

## المعاينة المحلية

لا تحتاج أي تثبيت. من مجلد المشروع شغّل خادمًا ثابتًا بسيطًا، ثم افتح `http://localhost:8000`.

```bash
# إن كان Python متاحًا
python -m http.server 8000

# أو باستخدام Node
npx serve .
```

> افتح الصفحات عبر `http://localhost` وليس بنقر ملف HTML مباشرة، حتى تعمل مشاركة الروابط وservice worker وGoogle Sign-In بشكل صحيح.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا باسم `zakhrafa` (أو أي اسم تختاره).
2. ارفع محتويات هذا المجلد إلى الفرع `main` — يجب أن يكون `index.html` في جذر المستودع.
3. من المستودع: **Settings → Pages**.
4. اختر **Source: Deploy from a branch**، والفرع `main`، والمجلد `/ (root)`.
5. احفظ، وانتظر دقيقة، ثم افتح:
   `https://YOUR-USERNAME.github.io/zakhrafa/`

### بعد النشر: حدّث روابط الموقع

ابحث عن `YOUR-USERNAME.github.io/zakhrafa` واستبدله برابطك النهائي في:

- جميع ملفات HTML (`canonical` وhreflang وOpen Graph وJSON-LD).
- `js/config.js` → `siteUrl`.
- `sitemap.xml` و`robots.txt` إن لزم.

> **ملاحظة مهمة:** أضف رابط GitHub Pages النهائي إلى **Authorized JavaScript origins** في Google Cloud Console (APIs & Services → Credentials → OAuth 2.0 Client IDs). مثال:
> `https://YOUR-USERNAME.github.io`
> وأضف `http://localhost:8000` أثناء الاختبار المحلي. هذا موضّح أيضًا كتعليق داخل `js/config.js`.

## إعداد Google Sign-In

تسجيل الدخول من جهة العميل فقط، ويستخدم مكتبة Google Identity Services:

- معرّف العميل موجود في `js/config.js` → `googleClientId`.
- الزر يُرسم عبر `google.accounts.id.renderButton` بنمط `filled_black` / `pill` / `large`.
- يُحفظ ملف تعريف مختصر فقط (الاسم، البريد، الصورة، `sub`) في `localStorage`.
- تسجيل الخروج يستدعي `google.accounts.id.disableAutoSelect()`.
- **لا تُحذف** بيانات المجموعة عند تسجيل الخروج؛ التخزين مرتبط بـ:
  - زائر: `zk_guest`
  - حساب: `zk_user_<sub>`
- عند أول تسجيل دخول تُدمج مجموعة الزائر تلقائيًا في الحساب.

لتغيير المعرّف أو البريد:

```js
// js/config.js
googleClientId: 'YOUR_CLIENT_ID.apps.googleusercontent.com',
contactEmail: 'you@example.com',
```

## تغيير اسم العلامة

كل شيء أساسي موجود في `js/config.js`:

```js
brand: {
  en: 'Zakhrafa',
  ar: 'زخرفة',
  tagline: { en: 'Names, beautifully written', ar: 'أسماء تكتبها بأناقة' },
  monogram: 'Z'
}
```

بعد التغيير، حدّث يدويًا:

- عناوين `<title>` و`meta description` وOpen Graph في صفحات HTML.
- `manifest.json` (الاسم والاسم المختصر).
- نصوص JSON-LD إن رغبت.
- `sitemap.xml` و`robots.txt` عند تغيير المسار.

## تغيير إعلان Monetag

الإعلان مقتصر على سطرين في `<head>` في كل صفحة، ولا يوجد أي كود إعلاني آخر:

```html
<meta name="monetag" content="13c120f9b2fa3bfb6f07aab7ec41938e">
<script src="https://5gvci.com/act/files/tag.min.js?z=10669434" data-cfasync="false" async></script>
```

لاستبداله:

1. استبدل هذين السطرين في **كل** ملفات HTML.
2. حدّث بيانات `ads` في `js/config.js` للتوثيق فقط.
3. لا تضف السكربت إلى `sw.js` ولا إلى قائمة التخزين المؤقت.

> لا تستخدم أكواد AdSense أو `adsbygoogle` أو `ca-pub`، ولا تضف شبكات إعلانية أخرى.

## الخصوصية والبيانات

- لا يوجد خادم، ولا رفع صور أو أسماء أو نصوص تهنئة.
- كل شيء يُحفظ في `localStorage` على جهاز الزائر.
- المفاتيح المستخدمة:
  - `zk_lang` و`zk_theme` للتفضيلات.
  - `zk_guest` للزائر.
  - `zk_user_<sub>` للحساب.
- التصدير ينتج ملف JSON يحتوي المفضلة والسجل، والاستيراد يتحقق من الملف ويدمج العناصر.
- تسجيل الخروج **لا يحذف** البيانات المحفوظة.
- صفحة `collection.html` تحمل `noindex, nofollow` ومستبعدة من `sitemap.xml`.

### إضافة نمط زخرفة

أضف عنصرًا إلى المصفوفة المناسبة في `js/decorations-*.js` بنفس شكل العناصر الموجودة (اسم عربي/إنجليزي، دالة تحويل، ووسم اللغة). ستظهر النتيجة تلقائيًا في الشبكة وفي صفحات الأقسام.

### إضافة قالب بطاقة

أضف دالة رسم جديدة في `js/card-templates.js` وسجّلها ضمن `TEMPLATE_NAMES`. كل قالب يستقبل `ctx` والأبعاد وخيارات النص، ويجب أن يعمل في المقاسين المربع والستوري.

## ملاحظات تقنية

- **بلا بناء:** لا npm، لا bundler، لا خطوة تصدير.
- **بلا تتبع خاص:** لا analytics مضمّن.
- **PWA:** `sw.js` يخزّن الملفات المحلية فقط، ويتجاهل أي طلب خارجي (Monetag، Google Fonts، Google Identity).
  عند تحديث أي ملف CSS أو JavaScript بعد النشر، ارفع رقم `CACHE` في `sw.js` (مثل `zakhrafa-static-v2`) حتى يستلم الزوار النسخة الجديدة.
- **Canvas والعربية:** يُعيّن `ctx.direction = 'rtl'` وينتظر `document.fonts.load` قبل الرسم.
- **الوصول:** تباين واضح، حالات تركيز، `aria-live` للنتائج والتنبيهات، واحترام تقليل الحركة.
- **المتصفحات:** أحدث Chrome وEdge وSafari وFirefox. المشاركة الأصلية تعتمد على دعم المتصفح، مع بديل تنزيل دائم.
